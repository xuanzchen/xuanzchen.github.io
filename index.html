Selected Work

All repositories ↗
  1. In progress Spatial multi-omics · GBM

    STATES-GBM Spatial Multi-omics Analysis

    STATES simultaneously profiles the spatial transcriptome and translatome, providing a joint view of RNA abundance and active translation in tissue. We are optimizing and extending the upstream processing pipeline and using STATES to investigate the spatial organization of GBM, with ongoing downstream analyses aimed at revealing tumor features and mechanisms.

    Spatial multi-omics · Spatial oncology · GBM

  2. Stanford Summer Research Scientific agents · Research software

    Bio-Babel

    Bio-Babel combines Agent Build, which reconstructs scientific software natively across language ecosystems, with Agent Read, which makes packages discoverable and callable by agents. We used it to rebuild and validate a Python plotting stack and selected analysis packages from R, and extended the framework to Python-to-C++ and Python-to-Rust translation.

    Scientific agents · Grammar of Graphics · Single-cell analysis

  3. Stanford Summer Research iST · Deep learning

    iST End-to-End Model

    We are developing an end-to-end model that maps raw fluorescence images directly to a gene-by-cell matrix through a shared latent space, bypassing separate registration, image processing, spot detection, decoding, and cell segmentation stages. By learning these steps jointly, we aim to reduce error propagation and information loss and generalize across experimental batches, microscope platforms, and iST technologies.

    Deep learning · iST · Vision Transformers · Foundation models

  4. In development iST · Scientific agents

    iST Upstream Processing Agent

    We are developing a scientific agent for iST upstream processing that automates data organization, quality control, parameter tuning, algorithm selection, and workflow orchestration. It is designed to help researchers configure and optimize complex pipelines across technologies and platforms, including registration, data augmentation, spot detection, decoding, and cell segmentation.

    Scientific agents · iST · Autonomous image processing · Workflow orchestration
