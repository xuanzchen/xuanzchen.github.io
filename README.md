# Xuanzhi Chen — Personal Website

Source for [xuanzchen.github.io](https://xuanzchen.github.io/).

The site is intentionally lightweight: plain HTML and CSS, no build step, and
automatic deployment through GitHub Pages. Its structure is inspired by the
clarity of academic homepages while the writing and visual system are original.

## Update guide

- Edit `index.html` to change the bio, links, or selected work.
- Edit `styles.css` to change colors, typography, or layout.
- Replace `assets/avatar.jpg` to update the portrait.

## Publish

Create a public repository named `xuanzchen.github.io`, place these files at the
repository root, and enable GitHub Pages from the `main` branch if it is not
enabled automatically.
